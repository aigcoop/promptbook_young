# 제품 프롬프트북

제품 사진(과 인물 사진)을 올리고 그대로 붙여 넣어 쓰는 한글 프롬프트북입니다. 지쿱AI대학교 · 지쿱파트너스 교육용입니다.

- 1권: 캐릭터·동물 + 제품 100개 (제품 사진 1장)
- 2권: 사람 + 제품 100개 (인물 사진 1장 + 제품 사진 1장)
- 번호마다 이미지 프롬프트와 10초 영상 프롬프트가 있습니다.
- 모음 화면에서 사진을 누르면 그 번호 페이지가 열리고, 공유 단추는 그 번호 링크만 보냅니다.

## 폴더 구성
```
index.html        모음 화면
p/1-001/ ~ 2-100/ 번호별 페이지 (index.html, photo.jpg, thumb.jpg)
assets/           공통 디자인(style.css)과 복사·공유 기능(page.js)
robots.txt        검색엔진 수집 차단
```

## GitHub Pages 켜기
저장소 Settings → Pages → Branch: main / (root) → Save
